## 3. AI가 후보 밖 장소·행사를 쓰면 어떻게 막는가

아래 AI 응답은 **검증 동작을 보이기 위해 일부러 틀리게 만든 테스트용 가짜 응답**이다(실제 Gemini 출력 아님).

| 후보 id | 대조 결과 | 걸린 이유 |
| --- | --- | --- |
| `read-10min@seoul-library` | 통과 | - |
| `read-toc@seoul-library` | 차단 | 확인되지 않은 장소: 마포중앙도서관 |
| `out-stay@seoul-library` | 차단 | 활동 시간 10분이 허용 범위 15~20분 밖, 없는 근거 id: F999, 근거 없는 일정: 오후, 근거 없는 일정: 3시, 근거 없는 조건: 무료 |
| `event:none` | 차단 | 후보 목록에 없는 id |

## 4. 확인되지 않은 장소·기간이 지난 행사는 후보에 들어가지 않는다

- `people-mindstore` — 운영 지점 미확인(서울마음편의점)
- `event:sample-past` — 행사 종료(2026-10-10)
- `event:sample-far` — 생활권 밖 행사(강남구)
- 통과: `event:sample-on` (같은 구, 기간 안)
